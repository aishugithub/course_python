# Foothold Python — your own copy of the course

A free, self-paced Python course for absolute beginners. Students type real Python in
the browser from the first lesson: about 470 small programs, each checked instantly,
with hints and an error coach that explains Python's messages in plain words.

This repository is the starting point for **teachers who want to run the course for
their own students**: on your own web address, with your students' sign-ins and progress
in **your own Google Sheet**. It costs nothing and needs no programming. Setting it up
takes about 30 minutes.

**Start here:** [TEACHERS_GUIDE.md](TEACHERS_GUIDE.md)

What you get:

- the whole course: lessons, exercises, challenges and mini-project tracks;
- your own record book (a Google Sheet) for sign-ins, progress and feedback;
- a class dashboard inside that Sheet: who is progressing, who has gone quiet, which
  programs the class finds hard, and the most common Python errors per unit;
- settings in one file (`config/course.config.js`) to hide, reorder or add lessons.
